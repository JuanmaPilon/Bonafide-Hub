# 📢 Bonafide - Rearmado del Core

¡Buenas gente!

Ya falta cada vez menos para la próxima season, así que queremos empezar a organizarnos con tiempo para llegar bien preparados.

Según lo que se conoce hasta ahora, **el 18 de agosto sería la fecha tentativa de inicio del nuevo parche**, así que queremos aprovechar estas semanas para rearmar el core y llegar con un panorama claro desde el primer día.

En **#eventos** vamos a publicar una **encuesta** donde les pedimos que se anoten con la mayor precisión posible para saber con quiénes contamos.

La idea es conocer:

- ✅ Quiénes tienen pensado raidear la próxima season.
- 🛡️ Qué clase y rol creen que van a jugar.

Lo de la clase es simplemente **a modo de placeholder**. Sabemos que de acá al lanzamiento pueden cambiar muchas cosas, ya sea por balance, ganas de jugar otra clase o cualquier otro motivo. No buscamos una decisión definitiva, sino tener una base para empezar a planificar el roster y, si hace falta, el reclutamiento.

Si hoy todavía no están 100% decididos, igualmente les pedimos que respondan con lo que creen que van a hacer. Siempre hay tiempo para actualizarlo más adelante, pero nos ayuda muchísimo tener una idea desde ahora.

¡Gracias!
